FAQ

What is Agent Hover?

A native Mac app that keeps an eye on the AI coding agents running on your machine. It lives in the notch, shows what each session is doing, and lets you answer permission prompts, check usage limits and track spend without switching windows.

Which agents does it work with?

Claude Code, Codex, Gemini, Cursor and OpenCode. Sessions from all of them show up in one list, on the board and in the notch.

How do permission prompts work?

Agent Hover installs Claude Code hooks so it can see tool calls as they happen. When an agent needs approval, the notch opens with the command and three buttons: Deny (⌘N), Always allow, and Allow (⌘Y). Always-allow rules are listed in Settings and you can remove them any time.

Does Agent Hover send anything over the network?

Your prompts, code and usage never leave your Mac: it reads your agents' session files on disk, and its hooks only talk to a listener on 127.0.0.1. The only network requests are checking your license key with Polar (our payment provider) and checking agenthover.app for app updates.

Does it change my Claude Code settings?

It adds its hooks to ~/.claude/settings.json and saves a backup next to it first. You can disconnect or reinstall the hooks from Settings.

How are usage limits calculated?

Codex limits come straight from Codex. Claude's 5‑hour and weekly limits are estimated from your local transcripts. You can also set the limits yourself in Settings.

Is there a free trial?

No. Agent Hover is a one-time purchase: you can download it any time, and it asks for a license key on first launch.

How do I get my license key?

Right after you buy, Polar emails you the key. Open Agent Hover, paste the key and click Activate. The 1, 3 and 5 Mac plans let you activate the same key on that many Macs.

What do I need to run it?

macOS 14 Sonoma or later, on Apple Silicon or Intel.

How do updates work?

Updates are included. Agent Hover checks for new versions once a day and installs them automatically, or you can choose Check for Updates… from the menu bar icon.

Can I move my license to another Mac?

Yes. Deactivate it in Settings → License on the old Mac, then activate it on the new one.
